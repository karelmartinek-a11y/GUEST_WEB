# Čtení průvodce přes OpenAI

Přímý pokyn uživatele z 10. 10. 2026 rozšiřuje původní statický profil o izolovanou hlasovou službu: „dokonči a nasad používání api key do produkce“. Uživatel předtím povolil přiměřenou placenou tvorbu hlasu. Obsah, překlady a mapy zůstávají statické; navigace zůstává vypnutá.

`scripts/build-speech.mjs` vytváří schválené katalogy všech 12 jazyků z lokálních obsahů, UI a již zobrazovaných pevných názvů/adres. Čte se aktuální stránka včetně textu pod přehybem, případně otevřený detail. Zavřené rozbalovací sekce se přečtou po jejich otevření a opětovném stisku čtení. Formuláře, vyplněná zdravotní karta, zdravotní poznámky, počty vybraných příznaků a GPS se nepředčítají přes API. Pořadí všech statických příznaků se nemění podle zdravotního výběru.

`POST /api/speech` přijímá pouze jazyk a ID schválených úseků, nikoli text. Služba načte obsah z právě nasazeného katalogu, ověří délku, vytvoří MP3 a uloží ji podle SHA-256 obsahu/modelu/hlasu. Klíč je pouze v rootem vlastněném `/etc/guest-web/speech.env` s režimem 0600; systemd ho předá procesu. Není v buildu, GitHubu ani prohlížeči. Návštěvník dostává označení hlasu vytvořeného AI.

Služba `guest-web-speech` naslouchá jen na `127.0.0.1:18781`, jako `guest-web`, s 192 MiB RAM, 25 % CPU a zápisem pouze do vlastního cache adresáře `/var/lib/guest-web/speech`. Nginx směruje jen `/api/speech` v projektovém vhostu. Limity: 10 kB tělo, nejvýše 40 ID a 1 000 znaků na tvorbu, 90 požadavků/min/IP, dvě souběžné tvorby, 512 MiB audio cache a 120 000 nově generovaných znaků za UTC den. Denní rezerva se atomicky uloží ještě před voláním poskytovatele a přežije restart. Limity nejsou garantovaný finanční strop účtu OpenAI; jeho limity spravuje vlastník účtu. Audio v cache se i po vyčerpání denního limitu dále přehrává. Při zaplnění cache služba odmítne novou tvorbu; nic automaticky nemaže. Nginx access log je vypnutý a služba neloguje těla ani obsah.

Model `gpt-4o-mini-tts`, hlas `marin`, MP3, jazyk podle vybrané stránky; instrukce požadují přesné čtení a klidný, vstřícný ženský projev. Model/hlas lze změnit v privátním prostředí `SPEECH_MODEL`/`SPEECH_VOICE`. Dokumentace OpenAI z 1. 10. 2026 oznamuje konec starších TTS snapshotů 6. 1. 2027; před tímto termínem je třeba ověřit alias a migrovat dle aktuálního API. Pro tento release bylo skutečné generování přes alias ověřeno.

Služba je samostatná infrastruktura, nikoli spustitelný upload statického deployment uživatele. Její rootem vlastněný kód `/etc/guest-web/speech.mjs` odpovídá `infra/speech.mjs`; jednotka odpovídá `infra/guest-web-speech.service`. Při změně serveru root zkopíruje otestovanou verzi a restartuje pouze `guest-web-speech`. Automatický statický deploy mění katalogy atomicky spolu s vydáním. Rollback hlasu: zastavit tuto jednotku a odebrat pouze její location z projektového vhostu, po `nginx -t` reload; ostatní vhosty, certifikáty a globální konfigurace se nemění.

Oficiální zdroje: [Text to speech](https://developers.openai.com/api/docs/guides/text-to-speech), [deprecations](https://developers.openai.com/api/docs/deprecations#2026-10-01-text-to-speech-models). České API generování je ověřené; kvalita ostatních jazyků vyžaduje poslech rodilým mluvčím. BN není ve zveřejněném seznamu garantovaných TTS jazyků, proto samotné úspěšné vytvoření souboru nebude označeno jako jazyková akceptace. Ovládání, síťové požadavky a pohyb úst v testech jsou simulované. Ústa jsou odhad časování podle audio přehrávání, nikoli fonémová data poskytovatele.
